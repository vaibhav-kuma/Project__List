# User Stories

## 1. User Registration and Login
**As a** new user,  
**I want to** register with my email and password and log in,  
**So that** I can securely access my personal expense data and groups.

## 2. Adding Manual Expense
**As a** user,  
**I want to** manually enter an expense with amount, date, category, and note,  
**So that** I can track my spending even when I don't have a receipt.

## 3. Scanning Receipt with Camera
**As a** user,  
**I want to** take a photo of a receipt,  
**So that** the app automatically extracts the date, merchant, and total amount to save me typing time.

## 4. Creating Expense Categories
**As a** user,  
**I want to** create custom categories (e.g., "Office Snacks"),  
**So that** I can organize my spending in a way that makes sense to me.

## 5. Creating a Group for Bill Splitting
**As a** user,  
**I want to** create a group and add friends,  
**So that** we can track shared expenses for a trip or household.

## 6. Adding Shared Expense to Group
**As a** group member,  
**I want to** add an expense and specify how it splits (e.g., equal or specific amounts),  
**So that** everyone knows their share of the cost.

## 7. Settling Up with Group Members
**As a** group member,  
**I want to** see who I owe and mark payments as "settled",  
**So that** we can clear debts and keep the group balance accurate.

## 8. Viewing Monthly/Weekly Reports
**As a** user,  
**I want to** view a chart of my spending by category for the month,  
**So that** I can understand where my money is going.

## 9. Setting Budget Limits
**As a** user,  
**I want to** set a maximum spending limit for specific categories (e.g., "Dining Out"),  
**So that** I can control my finances better.

## 10. Receiving Alerts When Budget Exceeded
**As a** user,  
**I want to** receive a notification when I approach or exceed my budget,  
**So that** I can stop spending in that category before it's too late.
