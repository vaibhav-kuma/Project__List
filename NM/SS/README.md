# AI-Powered Vulnerability Detection Engine

This project is a microservices-based AI-powered vulnerability detection engine.

## Services

- **Agent**: Responsible for collecting data from various sources.
- **Processor**: Responsible for processing and normalizing the collected data.
- **ML-Engine**: The core machine learning service for vulnerability detection.
- **API**: Provides a RESTful API for interacting with the system.
- **Alerting**: Handles alerting and notifications.

## Getting Started

### Prerequisites

- Docker
- Docker Compose

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/vulnerability-detection-engine.git
   ```
2. Navigate to the project directory:
   ```bash
   cd vulnerability-detection-engine
   ```
3. Start the services using Docker Compose:
   ```bash
   docker-compose up -d
   ```
